> *"Every match is made with love for my sweet Walaa."*

A delightful, responsive, feature-packed **Match-3 Candy Crush** style game built with pure HTML5, CSS3, and JavaScript, dedicated with endless love to **Walaa**.

## ✨ Game Features

- **Personalized Branding & Romantic Visuals**:
  - Cotton candy aesthetics, glassmorphism cards, and floating ambient hearts.
  - Handcrafted SVG high-definition candies (Strawberry Hearts, Lemon Drops, Orange Stars, Mint Gems, Berry Diamonds, Plum Sweets).
  - Sweet combo love toasts (*"Sweet!"*, *"Tasty!"*, *"Divine Walaa! ✨"*, *"Queen of My Heart! 👑"*).
  - Walaa Love Meter that triggers an explosive **Love Rush** with free Color Bombs!

- **Match-3 Mechanics & Special Candies**:
  - **Match 4 in a line**: Creates a **Striped Candy** that shoots animated lasers to clear entire rows or columns.
  - **Match 5 in a line**: Creates the **Walaa Love Bomb Donut**! Swap with any candy to clear all candies of that color.
  - **Match L or T shape**: Creates an explosive **Wrapped Candy** with double 3×3 shockwaves.
  - **Special Candy Combos**:
    - *Bomb + Bomb*: Mega board clear!
    - *Bomb + Striped*: Transforms all matching candies into striped lasers!
    - *Striped + Wrapped*: Giant 3-row × 3-column cross laser!
    - *Striped + Striped*: Full horizontal and vertical cross beams.

- **Synthesized Web Audio API Engine**:
  - 100% self-contained synthesized sounds (harmonic chimes, sweet pops, laser blasts, victory fanfares) with no external audio file dependencies.
  - Sound on/off toggle.

- **Intelligent Assist & Board Balancing**:
  - Automatic reshuffling with friendly animated banner if no moves remain.
  - Smart hint system that gently glows after 5 seconds of inactivity or upon pressing the 💡 button.

- **5 Handcrafted Levels + Endless Zen Mode**:
  1. *Level 1: Sweet Beginning* — Reach 2,000 points.
  2. *Level 2: Strawberry Romance* — Collect 16 Strawberry Hearts.
  3. *Level 3: Sweet Jelly Garden* — Clear 16 frosted jelly tiles.
  4. *Level 4: Sugar Sparkle Craze* — Forge 3 special candies and score 6,500 pts.
  5. *Level 5: Queen Walaa's Finale* — The Grand Finale score challenge!
  - *Endless Mode*: Relaxing infinity play without move limits.

- **Mobile & PWA Ready**:
  - Fully responsive on iPhones, Android phones, iPads, laptops, and desktops.
  - Can be added to the phone home screen as an app via the browser menu ("Add to Home screen").
